# Asteroids

A simple Asteroids-style arcade game built with **Python** and **Pygame**.

The player controls a spaceship, moves and rotates around the screen, and shoots incoming asteroids. Asteroids split into smaller pieces when hit.

## Features

* Player movement and rotation
* Shooting with a cooldown
* Asteroid spawning and splitting
* Collision detection
* Basic game logging
* Built with Pygame

## Controls

* **W / S** — Move forward / backward
* **A / D** — Rotate
* **Space** — Shoot
* **Close the window** — Quit the game

## Run

Install the dependency:

```bash
pip install pygame
```

Then run:

```bash
python main.py
```
